# 2026-11-01 图鉴、变异宝典与藏品

## 页面与数据

图鉴从个人页移至独立侧栏入口 `/illustrated`，包含作物图鉴、超变图鉴、藏品、变异宝典。手机侧栏使用相同菜单。作物、超变原有的购买、领取及账号隔离逻辑保留。

变异宝典分常规、装扮、藏品三类，读取官方变异配置、概率公示与系列资料，不需要运行账号。隐藏事件不作为普通变异展示；宝典的藏品系列按官方 `display` 规则筛选，珍藏室保留完整的五个系列、30 款藏品。

系列问号支持悬停查看及点击固定说明，键盘聚焦和手机点击也可使用。概率来自 `CollectionGroup.public_probability / 100`，按官方界面保留一位小数，保底次数取 `display_guarantee`。例如普通系列 4 / 8 / 12 / 24 小时的展示概率为 1.2% / 2.3% / 3.3% / 6.5%，保底分别为 120 / 60 / 40 / 20 次；该概率是系列变异概率，不表示单款藏品概率。

藏品通过 `gamepb.collectionpb.CollectionService.GetCollections` 读取蓝晶类别 `1`。请求、响应字段及字节与官方编码器和实际抓包核对；服务端未返回类别时保留错误，不把未知状态显示为空收藏。

显示系列、星级、重复持有数、展示状态、许愿状态、评分、奖励档位及激活／下一级所需材料。拥有副本不等于激活；当前评分使用服务端结果，已生效增益以 `claimed_reward_score` 为准，不把尚未领取的评分增益提前应用。

本次样本未验证藏品激活、升星、领奖、许愿和切换展台的写操作，页面仅提供读取。不会自动消费金币、重复藏品或道具。

## 游戏服务

`core/src/services/collections.ts` 提供共享的 `getCollectionsSnapshot()` 与本地宝典 `getMutationCatalog()`。藏品网络读取经现有账号 Worker 入口，重叠读取合并为一次请求；页面无需额外扩展即可独立使用。

## 验证边界

真实账号数据不作为测试输入，回归在忽略目录的独立工作区执行。浏览器预览仅使用模拟账号、收藏数据和只读接口。账号切换、停止账号或离开页面时，旧请求结果失效，失败状态可重试读取。原始抓包、解包代码、预览与测试产物不进入发布内容。

核心及客户端编译、前端类型检查、构建和修改文件 lint 通过。四类图鉴、筛选、搜索、详情、问号说明、深色主题及手机布局已用模拟数据核对，测试与预览产物不进入提交。

官方抓包与离线字节一致不等于长期在线验证，Node 宿主现有 ACEVM 能力限制保留。
